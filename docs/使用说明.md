# 使用说明（v1.2.0 公开版）

本版本**不包含任何游戏素材**：界面顶部的纸面横幅、五线谱、高音谱号、音符，以及窗口图标，
全部由程序绘制（谱号用的是系统字体 `Segoe UI Symbol` 的字形）。

---

## 一、支持哪些版本

| 版本 | 可执行文件 | 说明 |
|---|---|---|
| Steam 版（2023 重发） | `SR.exe`（3,371,472 B，MFC 构建） | 从 Steam 库目录自动查找 |
| 2007 流行版 | `SR.EXE`（2,324,480 B，Delphi 构建）；常见破解名为 `[交响乐之雨].SR_Cracked.exe` / `[交响乐之雨].SR.exe` | 需要你自己先启动游戏，再点「挂载补丁」 |

程序按**进程名**识别版本，再对钩子点逐字节校验；两个版本各有一套钩子地址、结构偏移和判定窗口。
校验不通过就只提示「字节不匹配，未做任何写入」，不会改动游戏。

---

## 二、运行

1. 解压后双击 `SRPerfectPatch.exe`（自包含单文件，不需要安装 .NET）。
2. Steam 版：程序会从注册表的 Steam 库路径里找 `...\steamapps\common\Symphonic Rain\SR.exe`，
   找到就**自动挂载**。
   2007 流行版：先自己启动游戏，再点「挂载补丁」（或「启动游戏并挂载」指向你选的 exe）。
3. 游戏里进入 **Free Play** 选曲，判定文字就会出现。

**卸载**：点「卸载补丁」，或直接关掉游戏（会自动还原）。

## 三、界面上有什么

| 区域 | 说明 |
|---|---|
| 状态栏 | 未连接 / 已挂载 (PID xxxx) / 已接管；右侧是实时 `FPS` |
| 三个按钮 | 挂载补丁、启动游戏并挂载、卸载补丁 |
| 复选框 | 游戏启动时自动挂载；开机自动启动；剧情演奏也弹成绩单；Perfect 显示毫秒数 |
| Language | 简体中文 / English / 日本語，切换立即生效并写回配置 |
| 显示模式 | 自动适配（按比例）/ 全屏预设（绝对）/ 窗口预设（绝对） |
| X / Y / 字号 / 停留 | 判定文字的锚点、字号、停留毫秒（2007 版有独立的一套） |
| 五个颜色 | Perfect / Good / Miss / 连击 / 描边色 |
| 保存并立即生效 | 写 `config.ini` 并即时应用 |
| 恢复默认设置 | 全部参数复位（含窗口大小、坐标） |
| 日志 | 只记录关键事件，同时写 `patch.log` |

**FPS** 只在演奏中出现：它统计的是游戏每帧更新判定逻辑的次数，所以在菜单/标题界面显示 `FPS —`。

## 四、热键

| 键 | 作用 |
|---|---|
| `F7` | 用示例数字预览成绩单（普通样板 / ALL PERFECT 样板交替） |
| `F8` | 自检：轮流显示 Perfect(+AP) / Good / Miss |
| `F9` | 重载 `config.ini`（改完不用重启） |
| `F10` | 显示 / 隐藏覆盖层 |
| `Ctrl+Alt+←/→/↑/↓` | 判定文字微调，每次 2px |
| `Ctrl+Alt+[` / `]` | 字号 −1 / +1 |
| `Ctrl+Alt+S` | 保存当前微调结果 |

演奏中也能用：一边弹一边把文字挪到不挡谱线的位置，按 `Ctrl+Alt+S` 存下来。

## 五、显示规则

* **Perfect**（金色）：判定档位 3。默认只显示字样；勾上「Perfect 显示毫秒数」后带 `Early/Late N ms`。
* **AP**：从开场到第一次出现非 Perfect 之前，`Perfect` 右侧有一个小号 `AP` 角标。
* **Good**（蓝色）：档位 2，第二行显示 `Early 37 ms` 或 `Late 12 ms`。
* **Miss**（灰色）：档位 0 / 1（含「按了键但没有音符」的空按）与漏音。
* **N COMBO**：与第二行同字号、同基线并排；Good / Miss / 空按 / 漏音都会清零。
* 所有文字都带深色描边 + 投影，白墙、亮窗、深色衣服上都看得清。

**判定窗口（两版不同）**

| 版本 | Perfect | Good | Bad | 时间基准 |
|---|---|---|---|---|
| Steam 版 | ±13.33 ms | ±53.33 ms | ±106.67 ms | 1/88200 s，基准 1/75 s |
| 2007 流行版 | ±20 ms | ±80 ms | ±160 ms | 1/88200 s，基准 1/50 s |

窗口是编译期常量，与分辨率无关；实际手感会再被帧率量化（帧率越低，有效窗口略宽）。

**成绩单**：一首曲子演奏完（或最后一个音符过去 1 秒）后淡入，显示
Perfect / Good（分 Early、Late）/ Miss / Score，停留 9 秒后淡出。中途退出不会弹。
整首没有任何 Good / Miss / 空按，或分数达到该曲理论最高分时，标题下多一行 `★ ALL PERFECT ★`。

成绩单会**等最后一个音符的判定字样停留完之后**再出现（延迟 = 「停留(ms)」+ 350，
默认 1250 ms），这样收尾那个判定也能看清，不会被成绩单直接盖掉。

## 六、配置（`config.ini`）

```ini
[behavior]
autoattach=1              ; 游戏一出现就挂载
storysummary=0            ; 剧情里的演奏是否也弹成绩单
showperfectms=0           ; Perfect 是否也显示 Early/Late 与毫秒
fitmode=auto              ; auto | full | window
x=440
y=456
xwin=440
ywin=444
x2007=268                 ; 2007 流行版专用锚点
y2007=303
fontsize=27
fontwin=26
font2007=18
fadems=900
colorperfect=#FFD24A
colorgood=#4DA6FF
colormiss=#A0A0A0
colorcombo=#FFECBE
showcombo=1
clickthrough=1
language=zh               ; zh | en | ja
windowwidth=0             ; 0 = 自动
windowheight=0
```

`fitmode=auto` 时，Steam 版的锚点与字号按 `客户区高度 / 720` 缩放：

* 全屏 1280×720 → `(440, 456)`、字号 27
* 窗口 1280×701 → `(440, 444)`、字号 26.3

2007 版**不缩放**，直接用 `x2007` / `y2007` / `font2007`（默认对应 640×480）。
两版界面布局不是等比关系，所以各存一套。

想微调位置就用 `Ctrl+Alt+方向键`，或直接改 ini 后按 `F9`。

## 七、常见问题

**判定文字不显示？**
先看日志里有没有 `覆盖层 fg=... 显示=是`。若一直是「否」，说明游戏窗口当前不在前台
（点了别的窗口）——本工具只在游戏处于前台时绘制。

**提示「字节不匹配，未做任何写入」？**
说明这个 exe 不是被验证过的版本（或已经被别的补丁改过）。重启游戏再挂载；
仍然不行就是版本不兼容，程序会拒绝改动，游戏不受影响。

**2007 版判定文字位置偏了？**
用 `Ctrl+Alt+方向键` 挪到合适位置，`Ctrl+Alt+S` 保存。换分辨率后需要重新对一次。

**提示「检测到上次运行遗留的补丁」？**
正常。上次程序被强杀，补丁还留在游戏内存里，这次直接接管而不是重复钩。

**成绩单不弹？**
默认只在 Free Play 弹。剧情里的演奏需要在界面勾上「剧情演奏也弹成绩单」；
2007 流行版没有可识别的模式字段，一律当 Free Play 处理。
另外中途退出（没到最后一个音符）也不会弹。

**FPS 一直是 `—`？**
只在演奏中出现（菜单界面不跑判定循环）。若演奏中仍为 `—`，请把 `patch.log` 发来。

## 八、安全

* 只改内存，**不改动任何游戏文件**，退出时逐字节还原。
* 打开进程只要读 / 写 / 查询权限，不是 `ALL_ACCESS`；无注入、无全局消息 hook、无网络代码。
* 三处钩子点写入前逐字节校验，不符即中止。
* 改写期间挂起游戏线程；代码洞是 W^X（执行页不可写）。
* 本程序崩溃不影响游戏。

细节见 [SECURITY.md](SECURITY.md) 与 [安全性审查报告.md](安全性审查报告.md)。
