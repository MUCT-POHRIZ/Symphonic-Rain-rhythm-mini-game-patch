# 更新日志

## v1.2.0（2026-11-25）

这一版的头号内容是**支持 2007 年流行版**，另外补上了实时帧率、ALL PERFECT 与 AP 角标。

### 新增

* **支持两个版本的《交响乐之雨》**
  * Steam 版（2023 重发，`SR.exe`，MFC 构建，3,371,472 B）
  * 2007 流行版（Delphi 构建，进程名 `[交响乐之雨].SR_Cracked` / `[交响乐之雨].SR` / `SR`）
  * 启动时按进程名自动识别，再逐字节校验钩子点；两个版本各有一套钩子地址、结构偏移与判定窗口，互不干扰。
  * 界面状态栏会显示当前连接的是哪一版（如「已挂载 (PID 21136)」），日志写「已连接 2007 流行版」。
* **实时帧率显示**：主界面状态栏右侧显示 `FPS 59` 这样的数值，1 秒刷新一次。
  * 只统计游戏自己的每帧更新调用，**只在演奏中出现**；菜单/标题界面显示 `FPS —`。
  * 因此它反映的是游戏实际渲染节奏（例如 2007 版默认 `FPSMode=30fps` 就显示 30）。
* **成绩单 ALL PERFECT**：整首没有 Good、没有 Miss、没有空按（或分数达到该曲理论最高分）时，标题下多一行金色 `★ ALL PERFECT ★`，日志也追加 ` · ALL PERFECT`。
* **Perfect 旁的 AP 角标**：从开场到第一次出现非 Perfect 判定之前，`Perfect` 右侧显示一个小号 `AP`；一旦出现 Good / Miss / 空按就永久消失。
* **Perfect 也显示毫秒（可选，默认关闭）**：勾上后 Perfect 也会带 `Early 6ms` 这样的副行，方便练习精确度。
* **对齐微调热键**：`Ctrl+Alt+←/→/↑/↓` 每次移动 2px，`Ctrl+Alt+[` / `]` 调整字号 1pt，`Ctrl+Alt+S` 保存。演奏中可以直接对齐文字。
* **2007 版专用坐标**：`x2007` / `y2007` / `font2007` 三个配置项；两版布局不是等比缩放关系，所以各存一套。

### 修复

* **中途退出仍会弹成绩单**：原先判断「是否弹完」的备用条件是「播放位置越过最后一个音符 1 秒」，中途退出后这个值会从野指针里读到垃圾数据，偶尔误判为已到结尾。现在要求同时满足「确实打到最后一个音符附近」。
* **接管已有补丁后帧率一直显示 `FPS —`**：接管路径没有补上帧计数点的原始字节，导致读取被跳过。
* **重复刷「检测到游戏进程」**：以前每秒写一次，现在只在进程变化时写。
* **英文 / 日文下诊断行漏翻**：`覆盖层 fg=…`、`矩形=…`、`字号=…` 现在也会翻译。
* **英文 / 日文下日志出现中文标点**：语言切换提示末尾的中文句号已去掉。

### 变更

* **默认关闭的开关，开箱就是关闭状态**：`showperfectms=0`、`storysummary=0`；用户勾选后会记住，并只写进当前这份 `config.ini`（不再跨副本复制配置）。
* **界面文案精简**：复选框去掉长括号说明，改为鼠标悬停提示（ToolTip）；判定来源一行缩短。
* **两套外观同步**：带美术版（自用）与公开版（不含游戏素材）由同一份源码构建，`-p:NoArt=true` 切换。
* 代码洞版本升到 SRP6：旧版补丁会被自动识别、还原并重装为新版（期间不动游戏文件）。
